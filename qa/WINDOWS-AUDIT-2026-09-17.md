# نتيجة فحص صفحات ونوافذ عقارتكم

التاريخ: 17 سبتمبر 2026. الموقع: https://aqartcom-v93.onrender.com

نجح الفحص الآلي بعد إصلاح الأعطال أدناه. الفحص البصري المباشر بالمتصفح لم يكتمل بسبب تعذّر اتصال المتصفح السحابي؛ لذلك لا تمثل هذه النتيجة اعتمادًا بصريًا لجميع النوافذ على الهاتف.

| الفحص | النتيجة |
|---|---|
| تحميل صفحات الموقع المنشور | 26 من 26 صفحة استجابت بنجاح |
| تشغيل واجهات الصفحات في محاكاة DOM | 44 سيناريو للزائر والمدير والمستضيف؛ 106 تحققات ناجحة |
| المسارات الداخلية في قاعدة بيانات معزولة | 179 طلبًا، دون أخطاء خادم غير متوقعة |
| التسجيل والدخول والتعديل والرفع والحذف والبحث | 51 خطوة ناجحة في بيئة معزولة |
| اختبارات الصلاحيات والحجز والوسائط والتقييمات وغيرها | 88 اختبارًا ناجحًا |
| سلامة صياغة JavaScript | 102 ملفًا، دون أخطاء صياغة |

يشمل فحص الواجهات تحميل جميع صفحات HTML، و23 تبويبًا للإدارة العامة، وتبويبات المكتب والاشتراكات، وحساب المستضيف، وتبويبات إدارة الفنادق للمدير والمستضيف. جرى فتح نوافذ الدخول والحساب ولوحة المالك والإضافة والتعديل والوسائط والبحث المحفوظ والتنبيهات، ونوافذ إضافة المنشأة والغرفة والأسعار والعروض والتوفر والعمولة، وتفاصيل الفندق والتقييمات ونموذج الحجز. جرى التحقق من إغلاق النوافذ المتاحة، وظهور عناصرها، ووجود معالجات أزرارها، وعدم ظهور طلبات مرفوضة أو مفقودة في السيناريوهات المصرح بها.

## الأعطال التي أُصلحت

| الموضع | العطل | التصحيح |
|---|---|---|
| تقارير المكتب | إعادة جلب التقرير باستمرار بعد كل عرض | طلب واحد مع الاحتفاظ بالنتيجة ورسالة خطأ وزر لإعادة المحاولة |
| محفظة المكتب | تكرار `/api` في روابط وسائل الدفع والصرف وشحن المحفظة | تصحيح روابط الطلبات |
| مالية المستضيف | طلب بيانات قنوات خارج صلاحيات المستضيف، فتظهر رسالة رفض | عرض مالية حجوزاته المحلية دون توسيع صلاحياته |
| عمولة الفندق | زر يشير إلى نافذة غير معرّفة | إضافة نافذة العمولة مع حدود إدخال وفحص صلاحية الواجهة |
| قنوات الفنادق | رابط سجل المزامنة غير موجود | استخدام المسار الفعلي وقراءة سجل المزامنة منه |
| عقارات وعملاء المكتب | حقل البحث ومرشح المرحلة بلا استجابة | ربط الحقول بتصفية الصفوف واختبارها |
| الفنادق التجريبية | رابط دخول يشير إلى صفحة غير موجودة | توجيهه إلى صفحة إدارة الفنادق التي تتضمن الدخول |

حُدّثت كذلك اختبارات قديمة كانت تفترض أرقامًا ثابتة للسجلات أو لا تراعي صورة معاينة الفيديو ونتائج المكاتب المضافة إلى البحث بالخريطة.

## حدود النتيجة

- محاكاة DOM تختبر الشيفرة والتفاعل المنطقي والطلبات، ولا تقيس التنسيق الفعلي أو اللمس أو أبعاد النوافذ على Samsung/iPhone. بعض وظائف رسم Canvas غير متاحة في هذه المحاكاة.
- استُخدمت مكتبة الخرائط لتشغيل منطق الواجهة محليًا؛ عرض بلاطات الخرائط والفيديوهات والتكاملات الخارجية بصريًا يحتاج متصفحًا متصلًا.
- لم تُنفذ دفعة حقيقية أو حجز حقيقي أو إرسال رسالة خارجية. اختبارات الكتابة والرفع والحذف استخدمت بيانات محلية تجريبية. لم يُستخدم حساب المستخدم الحقيقي داخل المتصفح.
- فتح تبويب الدفع أو قنوات Booking/Agoda/Expedia لا يثبت تفعيل حساب المزود أو نجاح عملية مالية/مزامنة خارجية فعلية. نافذة Moyasar الخارجية لم تُشغّل في المحاكاة.

## إعادة تشغيل الاختبارات

بعد تثبيت تبعيات التطوير:

```sh
npm test
npm run test:sections
npm run test:launch
npm run test:windows
```

يحفظ الفحص الأخير تفاصيل كل صفحة والطلبات ونتائج التحقق في `qa/windows-results.json`، وهو ملف نتائج محلي غير مضمّن في المستودع.
