# V35 Property Intelligence
Endpoints:
- POST /api/admin/property-ai/recalculate
- GET /api/admin/property-ai/dashboard
- GET /api/properties/:id/intelligence
- GET /api/me/recommendations

The valuation is deliberately transparent and deterministic: comparable median price/m² with confidence based on sample size and property completeness. It must not be represented as an accredited appraisal.
