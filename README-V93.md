# عقارتكم V93 — المحافظات والبلدات

هذا إصدار مصدر جديد مبني على V92 المصورة. يبدأ الاستخدام من index.html على خادم المنصة.

- اختيار المحافظة من 14 محافظة سورية، ثم كتابة اسم المدينة/البلدة/القرية في حقل يعرض اقتراحات المحافظة فقط.
- 7,599 اسمًا بعد إزالة الأسماء المتكررة داخل المحافظة من 7,605 سجلات مصدر. لا تمثل القائمة ضمانًا بحصر جميع القرى أو الأحياء؛ يمكن كتابة اسم غير مدرج مباشرة.
- تغيير المحافظة يمسح البلدة السابقة، وإعادة فتح تعديل الإعلان تحفظ القيم القديمة حتى إن لم تكن ضمن القوائم.
- دعم البحث العادي والجغرافي بالبلدة وحفظ البحث، وإضافة العقار وتعديله.
- التوافق مع التخزين الحالي: city للمحافظة وdistrict للبلدة أو الحي. لا يوجد ترحيل يحذف أو يغير بيانات الإعلانات القديمة. الأسماء المتماثلة داخل المحافظة لا تفصل بمعرف مستقل في هذا الإصدار.
- البيانات مضمنة في syria-localities.js ولا تحتاج اتصالًا بخدمة جغرافية خارجية. المصدر والترخيص في GEOGRAPHY-SOURCES.md.

## التشغيل والتحقق

اتبع خطوات الخادم في README-V92.md. فحص JavaScript واختبارات HTTP السابقة لا يغنيان عن اختبار قاعدة PostgreSQL. الحزمة مصدر وليست رابط موقع منشورًا أو APK/IPA جديدًا.

يبقى README-V92.md مرجع حدود الجاهزية السابقة. هذه الإضافة لا تعني اكتمال معالجة تلك الحدود.
