# V37 — Interactive Geographic Heatmap
- Interactive Leaflet/OpenStreetMap market map in Admin > خريطة السوق.
- Heat layers: price per sqm, demand, investment opportunity.
- Filters: city, sale/rent mode, property type.
- Property point markers with popup and direct property link.
- District aggregation circles and automatic map fitting.
- New API: GET /api/admin/market-map/geo.
- Uses only properties that contain latitude/longitude; indicators remain analytical, not official valuations.
