# V41 — Conversational Property Assistant

- Arabic natural-language property request parser.
- Multi-turn session context.
- Extracts city, property type, sale/rent, rooms, approximate area, budget and currency.
- Searches active Aqartkom inventory and prioritizes internal market opportunities.
- Floating assistant UI with clickable results.
- Conversation/session audit tables.
- This version uses deterministic NLP/rules and internal platform intelligence; it does not falsely claim an external LLM integration.
